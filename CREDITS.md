# Aurora Glass credits

Aurora Glass is an unofficial community theme for
[Seelen UI](https://github.com/eythaann/seelen-ui), which is distributed under
the GNU Affero General Public License v3.0.

The Aurora Glass CSS/SCSS and artwork were created for this project. No source
code was copied from the community themes listed below.

Visual references and compatibility targets:

- Apple Dock (`@nynele/apple-dock`) by nynele
- Immersive Toolbar (`@kenshi9999/ImmersiveToolbar`) by kenshi9999
- OnyxToolbar (`@bmw/OnyxToolbar`) by bmw
- Wave Animation for Taskbar (`@eythaann/dock-wave-animation`) by eythaann
- Grid Style Tray - Hover for Label (`@k-ivy/win-grid-tray-hl`) by K-Ivy

No external theme is required to use Aurora Glass.
